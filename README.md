### I will use Gmail
*I recommend you to create a dedicated Gmail address because TLDR send around 5 mails per days.*

- Create application on the [Google Cloud Console](https://console.cloud.google.com/)
- Enable [Gmail API](https://console.cloud.google.com/apis/library/gmail.googleapis.com?organizationId=0&supportedpurview=project) for your project
